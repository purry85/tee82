# 🤖 Tee82 카카오톡 PC 공지 무인 자동 수집기 사용 설명서

카카오톡 단체방(예: `골프락_그린피방`)에서 관리자가 올리는 **금액 인하 / 특가 / 할인 공지**를 사람이 복사하거나 입력할 필요 없이 **실시간으로 감지하여 크롬 확장 프로그램에 자동 반영**해주는 프로그램입니다.

---

## 🚀 1. 초간단 실행 방법 (더블클릭 1번!)

1. `카카오톡_공지수집기_실행.bat` 파일을 **마우스로 더블클릭**합니다.
2. 검은색 콘솔 창이 열리며 아래 문구가 표시되면 정상 실행된 것입니다:
   ```
   =================================================================
   🚀 Tee82 카카오톡 PC 공지 무인 자동 수집기 실행 완료!
   📡 [Tee82 API 서버 시작] http://127.0.0.1:18900/api/notices
   🎯 대상 카톡방 키워드: 골프락_그린피방, 골프락, 그린피방
   ⏰ 감시 주기: 3초 간격
   =================================================================
   ```
3. 이제 **PC 카카오톡에서 해당 단체방(`골프락_그린피방`) 대화창을 모니터 한쪽에 열어두시기만 하면 됩니다.**

---

## ⚡ 2. 작동 흐름

1. **카톡방에 새 공지가 올라옴**
   - 예: `양평TPC (공지) 10/20(화) 6:44 현장 13만!...`
   - 예: `솔트베이 [부분선결제 금액 인하] 10월 18일(일) 05:46 ~ 06:07 - 22.9...`
2. **수집기가 3초마다 새 공지를 자동 감지**
   - 콘솔 창에 `📢 [새 공지 자동 감지!]` 로그가 찍히며 내부 저장소에 보관됩니다.
3. **크롬 확장 프로그램(Tee82)에서 즉시 반영**
   - **자동 동기화**: 크롬 확장 프로그램을 켜거나, **[변환]** 버튼을 누를 때 수집기에서 최신 공지를 자동으로 가져와 즉시 적용합니다.
   - **수동 동기화**: [공지] 모달에서 **[🤖 카톡 수집기 동기화]** 버튼을 누르면 언제든 즉시 불러옵니다.
   - 공지 모달 상단에 `🟢 카톡수집기 연결됨 (N건 수집)` 배지가 표시됩니다.

---

## ⚙️ 3. 감시 대상 카톡방 변경 (`config.json`)

기본적으로 `골프락_그린피방`, `골프락`, `그린피방`이 설정되어 있습니다.  
다른 단체방 이름도 감시하고 싶다면 `config.json` 파일을 열어 `target_rooms`에 방 이름을 추가하세요:

```json
{
  "target_rooms": [
    "골프락_그린피방",
    "다른방이름",
    "유니아일랜드공지방"
  ],
  "auto_detect_golf_rooms": true,
  "poll_interval_sec": 3,
  "server_port": 18900
}
```

## ❓ 4. 자주 묻는 질문 (FAQ)

- **Q. 카톡 창을 최소화해도 되나요?**
  - 카톡 대화창이 윈도우 바탕화면 어딘가에 열려 있어야 텍스트를 읽을 수 있습니다. 다른 창 뒤에 가려져 있어도 괜찮지만, 작업표시줄로 완전히 최소화(`_`)하는 것보다는 창을 열어둔 상태로 두시는 것이 가장 안정적입니다.
- **Q. 일반 잡담이나 인사말도 공지로 수집되나요?**
  - 아닙니다! 구장명, 날짜(`10/20`), 시간(`6:44`), 금액(`13만`) 및 공지 키워드가 조합된 실제 그린피 공지 메시지만 정밀 필터링하여 수집합니다.
