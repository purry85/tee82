                        📱
                        

                            
📱 모바일(Lemur Browser) 최신 ZIP 업데이트

                            
스마트폰 Lemur Browser에서는 배치 파일이 지원되지 않으므로, 아래 버튼으로 최신 ZIP을 받아 확장 프로그램 메뉴에서 덮어씌워주시면 즉시 업데이트됩니다.

                        

                    

                    
                    

                        📱 Lemur 업데이트 방법 (30초 완료)

                        1. 위 [모바일 최신 배포 ZIP 다운로드]를 클릭하여 파일을 받습니다.

                        2. Lemur Browser 우측 하단 메뉴(점 3개) → [확장 프로그램] 클릭

                        3. 상단 [+(from .zip/.crx/.user.js)] 클릭 후 방금 받은 ZIP 파일 선택!

                        4. 기존 버전 위에 최신 버전이 즉시 덮어씌워져 업데이트가 완료됩니다.
                    

                


                
                

                    

                        2
                        

                            
⚙️ 최초 1회 원클릭 환경 등록 (연동 설정)

                            
크롬 브라우저 보안 정책상, 화면 버튼으로 업데이트를 실행하려면 PC당 최초 1회 등록이 필요합니다.

                        

                    

                    

                        📂 등록 방법 (1초 완료)

                        1. 아래 [원클릭_등록.bat 받기] 버튼을 누릅니다.

                        2. 다운로드된 '원클릭_등록.bat' 파일을 클릭하여 실행합니다.

                        3. 검은색 창에 [SUCCESS]가 뜨면 등록 완료! 아래 [연동 연결 테스트]를 눌러 확인하세요.
                    

                    
                    
                    

                        ※ 이미 '원클릭_등록.bat'을 실행하셨다면 다시 등록하실 필요가 없습니다.
