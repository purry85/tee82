티타임은 붙여넣기만,
등록은 오토매티가.

카톡·밴드로 받은 티타임을 붙여넣으면 6개 골프 플랫폼에 자동으로 등록하고, 가격이나 시간이 바뀐 타임만 골라 다시 수정합니다.

Windows용 다운로드 .exe 모바일(Lemur)용 받기
Ver 2.1.8 · Windows 10/11 · Chrome, Edge 지원

설치는 3분이면 끝납니다

설치 파일이 브라우저에 확장 프로그램을 자동으로 연결해 줍니다.

01

설치 파일 받기

위의 Windows용 다운로드 버튼으로 Automatee_Setup.exe를 받습니다.

02

실행하고 브라우저 선택

받은 파일을 실행한 뒤 사용하는 브라우저(크롬, 엣지)를 고릅니다.

03

툴바에서 바로 시작

[원클릭 브라우저 연동 및 시작]을 누르면 툴바에 오토매티가 나타납니다.

한 번 붙여넣고, 여섯 곳에 등록

사이트마다 다른 구장 이름도 매핑사전으로 자동으로 맞춰 줍니다.

골프몬등록 · 수정 · 리셋
골팡자동등록
골프탑홍보 등록
골마켓조인 등록
골프랜드조인 등록
골프락조인 등록

설치가 어렵다면 도와드릴게요
