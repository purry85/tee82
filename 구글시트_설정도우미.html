1단계 회원목록 스프레드시트 올리기

이미 같은 폴더에 회원목록.csv 파일을 생성해 두었습니다!
구글 드라이브를 열고, 회원목록.csv 파일을 화면 위에 마우스로 끌어다 놓기(드래그)만 하시면 헤더와 샘플 데이터가 완성된 스프레드시트가 바로 만들어집니다.

📁 Google Drive 열기 ➕ 빈 구글 시트 새로 만들기 (직접 만들 경우)
💡 직접 입력하실 때 1행 헤더:
A열: 아이디 | B열: 비밀번호 | C열: 만료일자(예: 2026-12-31) | D열: 상태(활성) | E열: 이름 | F열: 최근접속일시 | G열: 부여기능
⭐️ G열(부여기능) 팁: 빈칸(기본 일반회원 - 실험실 완전숨김), 속도해제(빠른손/초고속 기본활성), 전체리셋(리셋바 노출), 변동수정(변동/교체수정 버튼 노출), 전체(관리자 권한 & 실험실 오픈). 여러 개는 쉼표(속도해제, 전체리셋)로 부여 가능!
2단계 Apps Script 복사 및 배포

1. 구글 스프레드시트 상단 메뉴에서 [확장 프로그램] → [Apps Script]를 클릭합니다.
2. 기존에 적혀있는 내용을 모두 지우고, 아래 버튼을 눌러 복사한 코드를 붙여넣기(Ctrl+V) 합니다.

⭐️ 배포 설정 (가장 중요):
① Apps Script 상단 디스켓 💾(저장) 클릭
② 우측 상단 파란색 [배포] → [새 배포] 클릭
③ 톱니바퀴 ⚙️ 아이콘 눌러 웹 앱 (Web App) 선택
④ 실행 대상: 나 (내 계정)
⑤ 액세스 권한: 모든 사용자 (Anyone) 선택 *(필수)*
⑥ [배포] 누르고 화면에 나오는 웹 앱 URL 복사!
